# Security Policy

## Supported Versions

Only the latest release of Go Fuzz Action receives security updates. Older releases are not supported. Users are encouraged to upgrade to the latest release.

## Scope

This policy covers security vulnerabilities in Go Fuzz Action itself.

## Reporting a Vulnerability

To report a security vulnerability, please use [GitHub Private Vulnerability Reporting](https://github.com/dadrus/go-fuzz-action/security/advisories). Do not disclose vulnerabilities through public GitHub issues or other public channels.

Please include the affected version, a description of the vulnerability, steps to reproduce it, and its potential impact.

Reports are handled on a best-effort basis, with priority given to their severity and potential impact.

## Security Updates

Confirmed security vulnerabilities are prioritized according to their severity and complexity. Security fixes are documented in the release notes. Where appropriate, a GitHub Security Advisory is published to inform users of affected versions, available fixes, and mitigations.
